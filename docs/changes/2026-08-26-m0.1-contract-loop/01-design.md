# M0.1 委托调查 / 平板委托板 / 谈判 / 派遣 设计说明

日期：2026-08-26

## 目标

把当前“看任务 → 选佣兵 → 派遣”重构为 Fixer 核心循环：

```text
平板委托板 → 表面信息 → 是否调查 → 花调查点 → 获得情报
→ 重新评估委托 → 价格谈判 → 确定难度与价格 → 选佣兵 → 派遣
```

这是本次修改的最高优先级。

## 关键规则（已定）

- 平板最多同时显示 6 个普通待处理委托，主线任务不受限制。
- 普通委托有效期 1～7 天；每次结束一天，`remainingDays - 1`。
- 到期未处理则 `ContractExpired`，触发委托人/势力好感与 Fixer 信誉惩罚。
- 每天 `Investigation Points = 3`，调查动作消耗 1 点。
- 情报完整度决定评估与谈判权限：`>=0.40` 有限评估，`>=0.70` 完整评估。
- 玩家不能无依据地把 D 改成 S，只能落在已发现情报支撑的 `[minRank, maxRank]` 区间。
- 报价只能在任务定义的价格带内，客户会接受 / 还价 / 拒绝。
- 佣兵根据“等级 + 报酬 + 风险 + 性格”给出 Eager / Willing / Reluctant / Refuse。
- `ContractConfirmed = true` 后派遣按钮才可用。

## 保留与扩展

保留 GameState / MissionResolver / EventBus / 现有 UI 骨架，新增：

- `Contract` 状态对象
- 委托板 UI（卡片堆叠 + 详情 + 调查 + 评估 + 谈判 + 选人）
- 调查资源与情报写入
- 客户回应与佣兵态度计算

## 非目标

- 不做开放世界、战斗、车辆、商店等无关系统。
- 完整 Debug 面板与夜晚情报自动提示本次先不做，只保留数据接口。
